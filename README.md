# MDBKA
## Merangkak Dari Bawah Ke Atas

Aplikasi analisa trading berbasis screenshot.

Fungsi utama:

- Menempelkan atau mengunggah screenshot terminal trading
- Membaca data screenshot secara otomatis
- Mengoreksi hasil ekstraksi secara manual
- Menghitung skor analisa
- Menghasilkan keputusan BELI, JUAL, atau TUNGGU
- Menghitung S/L, T/P, risk-reward, risiko USD, dan lot
- Memberikan peringatan jika risiko melebihi batas equity
